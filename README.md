### Requisitos Funcionais

Código

Requisito

**RF01**

O sistema deve permitir que o usuário faça **login** com usuário e senha.

**RF02**

O sistema deve permitir **cadastrar um novo filme**.

**RF03**

O cadastro deve permitir informar **título, ano, gênero e nota de 0 a 10**.

**RF04**

O sistema deve permitir **enviar uma imagem da capa** do filme.

**RF05**

O sistema deve exibir os filmes cadastrados em uma **galeria visual com suas capas**.

**RF06**

O usuário deve poder **editar as informações** de um filme cadastrado.

**RF07**

O usuário deve poder **excluir um filme** da coleção.

**RF08**

O sistema deve permitir visualizar os **dados completos de cada filme**.

**RF09**

O sistema deve impedir o acesso à coleção por usuários que **não estejam autenticados**.

### Requisitos Não Funcionais

Código

Requisito

**RNF01**

O sistema deve possuir uma interface **simples e fácil de usar**.

**RNF02**

O sistema deve apresentar as capas dos filmes com **boa qualidade e organização visual**.

**RNF03**

As senhas dos usuários devem ser **armazenadas de forma segura**.

**RNF04**

O sistema deve ter **bom desempenho**, carregando as páginas e imagens rapidamente.

**RNF05**

O sistema deve ser compatível com **computadores, tablets e celulares**.

**RNF06**

O sistema deve garantir a **segurança dos dados** da coleção pessoal do usuário.

**RNF07**

O sistema deve possuir **disponibilidade e estabilidade**, evitando perda dos filmes cadastrados.

**RNF08**

O sistema deve permitir manutenção e futuras alterações de forma **facilitada**.
